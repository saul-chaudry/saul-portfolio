## Overview
Technical field notes: a precise, dark-blue systems workspace. Composition, language and navigation carry the identity; changing colors alone is insufficient. Saul's profile is a left-aligned engineering introduction, without centered greetings or skills tables.

## Colors
Use a midnight canvas, blue-white text and electric-blue links. Amber is reserved for small annotations. Keep borders quiet. GitHub itself controls its reading theme; use repository-owned SVG artwork for the masthead and normal Markdown for readable content.

## Typography
Use a system sans-serif for the website and monospace for indices, labels and annotations. GitHub README typography is native GitHub typography; do not imply DESIGN.md can override it.

## Layout
Use a broad top navigation and asymmetric hero on the website. Use a left-aligned title, short narrative, numbered work areas and a collapsed technical reference in the README. Avoid the centered name, social row, three-column practice table and seven-row toolkit-table pattern used previously.

## Elevation & Depth
Separate content using surfaces, fine outlines and generous space. No decorative terminal windows, fake charts, glowing metric displays or fabricated product screenshots.

## Shapes
Use rounded website panels and rectilinear engineering diagrams. Artwork must be static, repository-owned SVG with titles and descriptions. Narrative and key skills remain real text for mobile readability.

## Components
The profile consists of a blueprint masthead, narrative introduction, four capability notes, a public-work link and an expandable technical reference. The website consists of a system-map hero, capability panels, filterable project notes and direct email contact. Project status stays accurate.

## Do's and Don'ts
- Write in Saul's voice; preserve his identity, 8+ years and email from his own supplied profile.
- Keep the main identity Senior Software Engineer. Organize skills by engineering work, not separate job applications.
- Keep prototype scope and unimplemented integrations visible in project documentation.
- Do not copy Sohail's prose, tables, hero composition or green visual theme.
- Do not invent benchmarks, customers, certifications, history or contribution statistics.
